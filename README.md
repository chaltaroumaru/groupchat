# 🎪 学祭グループチャット

大学祭の出店チーム向けのグループチャットです。メンバー登録、ロールごとの権限管理、全体アナウンス、画像の共有ができます。

## 機能

| 機能 | 内容 |
| --- | --- |
| ログイン・アカウント認証 | メールアドレスとパスワードで登録します。確認メールのリンクを開くまでログインできません。 |
| ロール付与 | グループごとにロール(例: 代表 / 調理班 / 会計)を作成し、メンバーに付与できます。1人に複数のロールを付けられます。 |
| 複数チャット | 1つのグループに複数のチャットを作成できます(作成時に「全体チャット」が自動で作られます)。 |
| 指定ロール限定チャット | 🔒 制限付きチャットは、指定したロールのメンバーだけが閲覧できます。ロールごとに「閲覧のみ」か「閲覧・送信」を選べます。 |
| アナウンス | グループ全員への連絡を送れます。既読数を表示し、送信者と管理者は未読者を確認できます。新着はリアルタイムで通知されます。 |
| 参加者の権限編集 | チャットごとにメンバー単位で「閲覧・送信 / 閲覧のみ / 参加させない / 既定に従う」を設定できます。 |
| 画像の添付 | チャットとアナウンスに画像(JPEG / PNG / GIF / WebP、1枚10MBまで、1回5枚まで)を添付できます。ボタン、ドラッグ&ドロップ、貼り付けのどれでも添付できます。 |

チャットのメッセージ、権限の変更、アナウンスは Socket.IO でリアルタイムに反映されます。

### 権限の考え方

| 立場 | できること |
| --- | --- |
| オーナー(グループ作成者) | すべての操作、管理者の任命・解除、グループの削除 |
| 管理者 | ロール・チャットの作成と編集、ロール付与、参加者の権限編集、アナウンス送信、メンバーを外す |
| メンバー | 権限のあるチャットの閲覧と送信。「アナウンス可」のロールがあればアナウンスも送信可能 |

あるメンバーがチャットで持つ権限は、次の順で決まります。

1. グループ管理者・オーナーは常に「閲覧・送信」
2. 参加者ごとの個別設定があれば、それに従う
3. 制限付きチャットでは、持っているロールに許可された権限のうち最も強いもの(どのロールも許可されていなければ閲覧不可)
4. 通常のチャットでは、チャットの既定権限(「全員が閲覧・送信」または「全員閲覧のみ」)

閲覧できないチャットは一覧に表示されず、メッセージも添付画像も取得できません。添付画像も API を通して権限を確認してから配信します。

## 使い方

Node.js 22.13 以上が必要です(組み込みの `node:sqlite` を使うため、ネイティブモジュールのビルドは不要です)。

```bash
npm install
npm start          # http://localhost:3000
npm test           # API テスト
```

1. 「新規登録」からアカウントを作成し、確認メールのリンクを開きます。
   - SMTP を設定していない開発環境では、確認メールはサーバーのコンソールに出力されます。登録完了画面にも「(開発用)今すぐ認証する」リンクが表示されます。`NODE_ENV=production` ではこのリンクは表示されません。
2. 代表者がグループを作成し、「グループ設定 → グループ情報・招待」の招待コードをメンバーに共有します。
3. メンバーは「招待コードで参加」から参加します。
4. 「ロール管理」でロールを作り、「メンバー・ロール付与」でロールを付与します。
5. サイドバーの「チャット ＋」から、チャットや制限付きチャットを作成します。

## 環境変数

| 変数 | 既定値 | 説明 |
| --- | --- | --- |
| `PORT` | `3000` | 待ち受けポート |
| `BASE_URL` | `http://localhost:PORT` | 確認メールのリンクに使う公開 URL |
| `DATA_DIR` | `./data` | DB と画像の保存先 |
| `DB_FILE` / `UPLOAD_DIR` | `DATA_DIR` 配下 | 個別に保存先を指定する場合に使います |
| `SMTP_HOST` `SMTP_PORT` `SMTP_SECURE` `SMTP_USER` `SMTP_PASS` `MAIL_FROM` | なし | 確認メールの送信設定 |
| `NODE_ENV` | なし | `production` にすると開発用の認証リンクを返しません |
| `COOKIE_SECURE` | `false` | HTTPS で公開するときは `true` にします |
| `TRUST_PROXY` | `false` | リバースプロキシの内側で動かすときは `true` にします |

## 構成

```
src/
  server.js          起動処理(HTTP + Socket.IO)
  app.js             Express アプリの組み立て
  db.js              SQLite スキーマ
  auth.js            セッション(HttpOnly Cookie)
  permissions.js     グループ・チャット権限の判定
  uploads.js         画像アップロード(形式・サイズ・中身の検証)
  realtime.js        Socket.IO 配信(閲覧権限のあるユーザーにだけ送信)
  routes/            auth / groups(メンバー・ロール)/ channels(チャット・メッセージ・参加者権限)/ announcements(アナウンス・添付配信)
public/              フロントエンド(ビルド不要の HTML / CSS / JS)
test/                API テスト(node:test)
```
